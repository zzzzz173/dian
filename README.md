随机森林模型
本次代码采用了经典的随机森林模型进行了对iris数据集的分类问题，采用基尼系数作为分裂准则，通过不断的循环找到最佳分裂点即基尼系数最小的点，并以此来作为阈值，基尼系数计算效率高，对分类问题具有更高的鲁棒性，而信息增益和信息增益率计算较为复杂，并且可能过拟合。此外，我们采用了bootstrap采用即有放回的采用方法，对于本次数据集数据量较小可以重复的利用数据。此外我们引入随机性，在分裂时已当前时间作为随机种子，保证了模型的泛化性，为了防止模型的过拟合，我们采用k折交叉验证的方法，这里我们取k=5，最后我们进行准确率的评估和过程的可视化，我们计算准确率大约在90%到1之间，然后我们绘制结果预测对比图，混淆矩阵以及四个特征对结果影响的重要性的图像，由于测试集的数量过少，准确率变化明显。最后我们实现了基于iris数据集的随机森林模型的构建以及可视化。
