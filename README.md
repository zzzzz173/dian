首先第一个多头注意力：
我们定义MHA的类，对KQV进行线性变换将其投射到不同的特征子空间中，然后我们计算注意力的权重，进行softmax计算除以根号下句长，最后乘以V矩阵。
MHA中我们每个注意力头都是独立计算其KQV的，因此我们引进其两种变种，MQA和GQA，MQA即为多Q值，但其KV值每个头都共用一个，这样可以大大减小KV cache，而GQA则是这前面两种的折中选择，
将Q分组，每组Q共用相同的K和V。
虽然MQA和GQA的KV cache较小，但是其表达能力，准确率却没有MHA高，这是一个用效率换资源的例子。
在定义完三种类后，我们随机输入一个X，我们发现最后3种输出的size和注意力权重的size都是一样的，而3种注意力的差异较小。
第二个潜在注意力机制（MLA）
通过我的学习，MLA与前面注意力机制的显著区别就是：它对KV值进行了低秩分解，显著减小了KV cache的大小，从而减小了内存的占用。
实现MLA的流程（简单实现，目前没有加入Rope位置编码，）：我们定义一个MLA类，我们将输入变量的KV值进行低秩分解，将低秩的kv映射到原始空间，计算注意力分数，应用注意力权重，最后映射得到最终输出。
