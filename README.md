# dian
2025dian春招算法方向
本次模型运用bert模型进行bangumi动漫评论的预测评分。
模型架构:
我们使用huggingface中的已经预处理的bert模型进行微调，将其设置为回归任务，输出单个的连续值。
我们通过爬虫脚本，爬取了bangumi中动漫评分榜中的第一页的全部动漫的评论，由于评论数过多，我们每部动漫取其十分之一的评论数
对于初始爬取的数据我们要对其进行数据的预处理，对文本进行清洗，包括去除多余空格和符号，删除重复字符等，在进行训练时，我们发现由于
我们获取的是排行榜前部的动漫评论，大多数评论都是较高的分数，这样会造成我们的预测器在高分部分可能预测的很好，但在低分时却不是很准确，导致整体在验证集上的表现不佳
于是我们进行对数据的简单分类，将1-10分的评论分为10个桶，我们取桶中评论数的中间数，然后乘以1.5作为每种评论数的最大取值，对样本较少的进行上取样，对样本较多的进行下取样，平衡训练集分布，这样我们就将原本8832条评论数缩减到了800多条，
这样可以有效增加模型的拟合度。
训练过程：
我们使用adamw优化器，adam可以动态调整学习率，而w可以减少过拟合。
损失函数我们使用自定义的损失函数：0.4*MSE+0.3*MAE+0.3*Huber
我们财通学习率调度，采用线性 warmup 策略，warmup 比例为总训练步数的 10%。
使用梯度裁剪，防止梯度爆炸。
我们设置早停机制，如果验证集损失在5个epoch内没有改善提前终止训练，防止过拟合。
性能评估：
我们使用R方，MAE,MSE来评估模型的性能，绘制图像，预测值与真实值的散点图展示模型的预测性能和训练效果。
我们进行20个epoch，保存训练中拟合效果最好的一次。
